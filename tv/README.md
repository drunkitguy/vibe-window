# Vibe Window TV

Samsung Tizen TV client for Vibe Window, based on
[brightcraft/moonlight-tizen](https://github.com/brightcraft/moonlight-tizen) v1.19.0 (GPL-3.0).
The upstream README is kept as [README.upstream.md](README.upstream.md).

Builds come from `.github/workflows/tv-release.yml`, which runs this directory's `Dockerfile`.
The plan is in [docs/tizen-tv-plan.md](../docs/tizen-tv-plan.md).
